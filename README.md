# View Finder (뷰 파인더) — Minecraft Forge 1.20.1

모서리와 꼭짓점을 45도로 깎은 육면체를 화면에 띄워, 지금 어느 방향을 보고 있는지 보여 주는 클라이언트 전용 모드입니다.

## 기능
- 월드에 들어가면 화면 **맨 오른쪽 위**에 자동으로 표시
- 육면체가 시점에 맞춰 회전 — 가운데 보이는 면이 지금 바라보는 방향 (오른쪽 면 = 내 오른쪽, 위쪽 면 = 머리 위)
- 면 6개 + 깎인 모서리 12개 + 깎인 꼭짓점 8개 = **26개 방향**을 클릭해서 바로 그 방향 보기 (부드럽게 회전)
- 뷰 파인더를 잡고 끌면 시점이 함께 빙글빙글 회전
- 우클릭 드래그(또는 Shift+드래그)로 뷰 파인더를 원하는 위치로 이동 — 위치는 저장됨
- 아래에 현재 방위·각도 표시 (예: `북동 45° · 아래 20°`), 마우스를 올리면 그 영역의 방향 표시

## 조작
| 동작 | 방법 |
|---|---|
| 마우스로 조작하기 | **왼쪽 Alt를 누르고 있기** (키 설정에서 변경 가능), 채팅창(T)이 열려 있을 때도 가능 |
| 그 방향 보기 | 면·모서리·꼭짓점 클릭 |
| 시점 돌리기 | 좌클릭으로 잡고 드래그 |
| 위치 이동 | 우클릭 드래그 / Shift+좌클릭 드래그 |
| 크기 조절 | 뷰 파인더 위에서 마우스 휠 |
| 위치 초기화 | 가운데(휠) 클릭 |
| 표시 켜기/끄기 | 키 설정 → 뷰 파인더 → 표시 켜기/끄기 (기본 미지정) |

설정 파일: `config/view_finder-client.toml` (크기, 투명도, 회전 속도, 애니메이션 시간, 누르기/토글 방식 등)

## 빌드
GitHub Actions가 push할 때마다 jar를 빌드합니다 (Actions → 최신 실행 → Artifacts → `view_finder-jar`).
로컬 빌드: Gradle 8.8 + JDK 17로 `gradle build` → `build/libs/`.
